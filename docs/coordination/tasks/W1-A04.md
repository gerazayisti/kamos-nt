## Deliverables
1. `docs/architecture/memory.md`: the design, built on ADR-0005, `mm.h` (address spaces as
   amended by RFC-0001) and `boot.h` (what the memory map contains and what you must reserve:
   kernel image, modules, boot structure, first MiB, framebuffer, ACPI). Include the lock order
   for your locks (ranks 30, 60, 70) and the fault-fixup contract for `MmCopyFromUser` with A03.
2. **Physical memory:** boot allocator, then frame database (state, reference count, flags),
   with a bitmap or equivalent, double free and wrong-state detection.
3. **Page tables:** four-level map, unmap, protect, translate on a *simulated physical memory*
   behind a small access layer, so the same code runs on the host and later in the kernel.
   Rules to enforce and test: canonical addresses, alignment, W and X never together, NX,
   user/kernel mismatch, already-mapped, out of frames, nothing half-done after a failure.
4. **Pool:** size classes and large allocations, poison patterns in debug, accounting by tag.
5. Tests in `tests/mm/` on the host with ASan and UBSan (A10 provides the harness; until it is
   there, use your own target and move to theirs). Tests read back the simulated page tables
   to check real entries, not return codes alone.
6. Kernel stacks with guard pages: design only.
