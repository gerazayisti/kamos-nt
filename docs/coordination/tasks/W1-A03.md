## Phase 1 deliverables
1. `arch/x86_64/boot/`: Multiboot2 header, entry that checks `EAX == 0x36D76289` and keeps
   `EBX`, 32-bit to 64-bit trampoline (PAE, `EFER.LME`, `EFER.NXE`, paging), initial page tables
   mapping the kernel at ADR-0002's addresses, stack, BSS clearing, call of the C entry.
   `kernel.ld` per ADR-0002. Document the exact CPU state at entry in
   `docs/architecture/boot-contract.md`.
2. Serial console on COM1 (16550), `kprintf`, panic, `ASSERT` backed by `KeBugCheckEx`, version
   banner. `ntoskrnl/rtl/` minimum (strings, formatting). Nothing allocates.
3. `HalGetBootInformation` as specified in `boot.h`: validate the Multiboot2 structure, copy
   into the fixed arrays, normalise the map, bug check with `KAMOS_STOP_BAD_BOOT_INFORMATION` on
   anything malformed or too large. Threat model B1 is your test list.
4. A deliberate `ASSERT` failure that produces a recognisable line, and a GDB walk to the C
   entry documented (the architecture-mode question is A02's, coordinate through the inbox).
5. Propose the entry point name (the plan calls `KiStartKernel` provisional); A01 records it.

## Phase 2 deliverables
6. GDT, TSS (RSP0, IST stacks for #DF, NMI and #MC), IDT of 256 entries, exception stubs with one
   frame layout documented against the push order, handlers #DE, #UD, #GP, #PF (CR2, error code
   decoded). Only vectors 8, 10 to 14, 17, 21, 29, 30 push an error code.
7. PIC remapped, spurious IRQ7 and IRQ15 handled, PIT, CPUID, port I/O (`hal.h`).
8. **Execution levels exactly as ADR-0009 now says**: per-CPU software level, `IF` clear at
   `DEVICE_LEVEL` and above, `DISPATCH_LEVEL` as pending bits, the timer handler requests the
   dispatch interrupt and never switches threads. You implement `KeGetCurrentIrql`,
   `KeRaiseIrql` and `KeLowerIrql` in `hal/` for now (A05 takes them over at the start of Wave 2,
   hand-over through A05's inbox).
9. A fault-fixup table for faults inside `MmCopyFromUser`/`MmCopyToUser`: design it with A04
   (inbox), implement the mechanism and the `#PF` hook; A04 provides the copy routines later.
10. Timer calibration and a monotonic clock for `HalQueryMonotonicTime`.
